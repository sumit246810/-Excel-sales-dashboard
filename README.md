# 📊 Vrinda Store Data Analysis — Excel Dashboard

## 📌 Project Overview

This project is an Excel-based sales data analysis and dashboard project created to practice and demonstrate data analysis skills using Microsoft Excel.

The project focuses on analyzing store sales data and presenting important business information through data cleaning, calculations, Pivot Tables, charts, and an interactive dashboard.

## 🎯 Project Objectives

* Analyze sales performance
* Understand customer and order data
* Identify important sales trends
* Compare sales across different categories
* Create meaningful KPIs
* Build a simple and interactive Excel dashboard
* Practice data cleaning and Excel functions

## 🛠️ Tools & Skills Used

* Microsoft Excel
* Excel Tables
* Data Cleaning
* Excel Formulas
* IF Functions
* Pivot Tables
* Pivot Charts
* Data Visualization
* Dashboard Creation
* Basic Data Analysis

## 📊 Dashboard

The dashboard provides a visual summary of the store's sales data and helps understand the overall performance of the business.

### Key areas analyzed

* Sales
* Orders
* Customers
* Product categories
* Customer demographics
* Sales performance

## 🔍 Analysis Process

### 1. Data Preparation

The raw dataset was organized and converted into an Excel Table to make the data easier to manage and analyze.

### 2. Data Cleaning

The dataset was checked and prepared for analysis by organizing the data and ensuring the required fields were suitable for analysis.

### 3. Data Analysis

Excel formulas and Pivot Tables were used to analyze the dataset and calculate useful metrics.

### 4. Data Visualization

Charts and dashboard elements were created to make the results easier to understand.

## 📈 Key Insights

The dashboard can be used to identify:

* Sales performance patterns
* High-performing categories
* Customer-related trends
* Differences between customer groups
* Areas that may require further analysis
